# Compositor for Windows 0.8.0

Phase 4's clipboard, painting and retouching tools and Phase 5's editable text,
live shapes and Stroke / Drop Shadow editing are available in this release.

- Windows PNG/DIB clipboard interoperability, Cut/Copy/Paste, editable internal
  text records, floating-selection transforms and one undo per gesture.
- Brush, Eraser, mask painting, Blur, Clone Stamp, three Spot Healing modes and
  Content-Aware Fill with preview, Cancel and Apply.
- Point and fixed-box text with UTF-16 font/color runs; shapes redraw on resize.
- `.comp` format 11 interoperability with Compositor for Mac 1.4.5.
- Cooperative large-image jobs and exact packed RGBA downsampling.

The Phase 5 local acceptance checkpoint passes 628 native tests, 287 unit tests,
199 functional cases, all 29 original performance cases, eight native UI groups,
nine complete Mac PNG comparisons and four protected clipboard protocols.
Historical failures and qualifications remain in the repository's acceptance record.
Hosted release CI separately runs source/browser checks and portable ZIP integrity;
it does not replace local hardware timing, native clipboard or Mac gesture evidence.

Download the portable ZIP, extract it and run `Compositor.exe` on Windows x64
with Microsoft Edge WebView2 Runtime. The release includes `SHA256SUMS.txt` and
`release-manifest.json` to identify the exact build and source commit.

Liquify and Smudge are Phase 6 development work and are not part of 0.8.0.
