# Compositor for Windows 0.11.0

This update brings the Mac Compositor 1.4.10–1.5.7 feature changes to Windows.

- Edit 16-bit and HDR layers, import/export high-precision formats, and preserve precision through project saves. Projects read through format v17 and save the lowest format required by their contents.
- Use CMYK soft proofing and print export with a printer ICC profile, import PDF pages as layers, and decode HEIF using the bundled decoder without a Microsoft Store HEVC extension.
- Create progressive blur, RGB Split and Lens Effects; export Channel Pack images; open PSD artboards as separate documents.
- Edit GIF frame sequences, timing and playback; use pressure-sensitive brushes, layer search, font search and a compact toolbar.
- Updated Camera Raw processing, content-aware fill/healing, editable line styles, keyboard shortcuts and workspace navigation follow the fixed Mac 1.5.7 source.

## Compatibility

High-precision and new spatial-filter display currently uses the CPU reference compositor. Some Apple Core Image effects are approximations; fonts, GPU arithmetic and decoder output are not universally pixel-identical. HEIF chroma reconstruction differs at subsampled edges; HDR gain-map reconstruction is not implemented. CMYK TIFF import currently converts to 8-bit RGB. See the detailed upstream comparison for measured differences and supported limits.

Extract the complete Windows x64 portable ZIP and run `Compositor.exe`. Keep the RAW and HEIF helpers, runtime DLLs and all notices beside the application. Edge WebView2 Runtime is required. No installer, signing or automatic updater is added.
