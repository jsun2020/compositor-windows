# Compositor for Windows 0.10.0

This release delivers the Windows update for Mac Compositor 1.4.9.

- Camera Raw uses the measured 1.4.9 colour tables, revised detail processing, reusable preview calculations and 16-bit sensor-to-display dithering.
- New Canvas supports physical units, DPI and background choices. Rotate Canvas preserves layers, masks, guides and selection in one undo step.
- Search Commands, Last Filter, fullscreen, Navigator and Ctrl+middle-button zoom improve navigation and repeat editing.
- Export As supports PNG, JPEG and single-page PDF with output sizing, background choices and DPI-correct page dimensions. WebP import/save/reopen and size limits remain covered.
- Scanlines includes preview, cancellation, Apply/Undo/Redo and Last Filter. Its Glow path matches the verified Mac final-pixel fixtures.
- Translucent inner effects preserve source alpha. Canvas/DPI changes retain editable layer properties where no pixel resampling is required.
- Large-image display/preview reductions use bounded intermediate storage. Selection deletion and eligible gradient paths preserve exact pixels while avoiding redundant work. React effect replay retains one canvas renderer.

## Validation and provenance

The implementation passed 751 native engine/shell tests, 310 frontend unit tests and 344 browser functional tests. All original 29 CPU and 4 GPU performance cases passed on the attended Windows test machine, with unchanged budgets, one worker and zero retries. Ten originally ignored native diagnostics remain excluded; the 33 browser performance opt-ins are covered by those separate hardware runs.

The locally validated production candidate passed ZIP integrity and source/WASM checks, six real Canon RAW and six preview-free synthetic DNG developments, 25 actual Windows file dialogs and independent Pillow/PyMuPDF export checks, including a 100 MP PDF. Current production WASM matches 31 legal Mac Glow spacings plus five original Scanlines recipes byte for byte. The attended run preserved the existing screen saver policy.

That local candidate retained the pre-release 0.9.0 version label. This 0.10.0 release is rebuilt from the committed source after version/documentation updates and must pass the repository's Windows CI before publication. Hosted CI does not replace the separately recorded local hardware/native or Mac evidence. `release-manifest.json` identifies the published ZIP's actual build marker, source commit, WASM and file hashes; `SHA256SUMS.txt` verifies the downloaded files.

## Compatibility

Projects still read `.comp` versions 1–11 and write version 11. Camera Raw and translucent inner-effect output can differ from the older Mac 1.4.5-based release. LibRaw and Apple CIRAWFilter, fonts and GPU arithmetic are not universally identical; the byte-exact claims apply to the recorded fixtures. Four historical intermediate MPS half-plane differences remain documented without changing the verified final outputs. The 100 MP image/mask limit, 256 MiB history cap, reduced large previews and declared PSD/PSB limitations remain in effect.

Download the Windows x64 portable ZIP, extract every file and run `Compositor.exe`. Edge WebView2 Runtime is required. Keep the RAW helper, runtime DLLs and license notices beside the application. No installer, signing, automatic updater or project-format migration is added.
