# Compositor for Windows 0.9.0

This release delivers Liquify/Smudge, Camera Raw, layered Photoshop import and camera sensor RAW development, together with the final affine and convex-distortion sampling corrections.

- Press **R** and choose **Liquify** or **Smudge** under **Mode**. Live strokes respect effects, masks and selections; Escape cancels and mouse-up commits one undo step.
- Camera Raw provides Light, Color, curves, Color Mixer, Point Color, Color Grading, Effects, Detail, Optics, Geometry and Calibration, with preview/cancel and editable history.
- RGB 8-bit PSD/PSB raw/PackBits import retains supported layers, folders, masks, adjustments, first-style text and live shapes, and reports unsupported records.
- The pinned LibRaw helper develops actual camera sensor data with bounded preview and full-size import. It does not replace RAW decoding with an embedded JPEG.
- Rotated affine edges, reduction byte phases and grayscale clipping match the received Mac sampling probes. Convex free distortion uses the measured Core Image premultiplied filter and clear input extent while preserving the saved sampling metadata.
- Closing the last document clears the picture. Modified documents have explicit Save and Close, Don't Save and Close and Cancel Close choices.
- Builds now independently validate the WASM binary and all JavaScript-required exports. A successful compiler exit cannot make a truncated binary acceptable.

Mac comparisons cover independently returned fixed fixtures, including the four Camera Raw recipes and 42 sampling cases. Ordinary sampling/distortion RGBA records are exact; six mask-related records have at most one-byte differences. This does not establish universal font, camera colour or GPU arithmetic equivalence. Large previews, the 100 MP image/mask limit and 256 MiB history cap remain in effect. PSD ZIP compression, 16/32-bit and non-RGB formats are refused.

Download the Windows x64 portable ZIP, extract every file and run Compositor.exe with Edge WebView2 Runtime installed. Keep the RAW helper, runtime DLLs and license notices beside it. SHA256SUMS.txt and release-manifest.json identify the exact source and build.

The [final acceptance record](https://github.com/jsun2020/compositor-windows/blob/main/docs/superpowers/plans/2026-10-09-phase35d-and-final-release.md) separates source CI, unchanged hardware budgets, native production package checks and actual Mac evidence. Historical failures remain retained. Published 0.8.0 artifacts are unchanged.
