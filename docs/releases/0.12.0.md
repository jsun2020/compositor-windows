# Compositor for Windows 0.12.0

This update brings Mac Compositor 1.5.11 features to Windows.

- Align selected layers to the canvas, selection or each other, and distribute their centers or spacing. Groups and linked masks follow the operation; undo restores it as one step.
- Use Vignette, Lens Effects, Tonal Contrast and Sharpen as editable adjustment layers. The new Sharpen filter and colored Vignette also work directly on a pixel layer; Vignette can create an edge overlay on an empty layer.
- Refine Prism with Blur, Fringe and one-way/two-way copies. Bright-source density extends the lens threshold to 100.
- Crop to 2.39:1 or a custom width:height ratio. Space temporarily switches to the hand cursor without stealing typing or control activation.
- Save the lowest project format required by the content, through version 20. Existing lower-version projects retain their original compatibility when no new features are used.

Windows uses portable approximations for Core Image optics. Reference comparisons are documented in the technical report; this is not a claim of identical rendering for every optical effect. Lens Effects retain a bounded working-memory limit. A render exceeding that limit reports an error and leaves the document editable; use a smaller canvas or disable that adjustment for a full-resolution export.

The portable app includes its HEIF decoder and RAW helper. No Microsoft Store HEVC extension is required.

Local Windows acceptance completed on 2026-10-28: 371 functional, 29 CPU and 4 GPU cases; production-package RAW checks; and three native UI groups covering 61 real dialogs. See the [acceptance report](../../pair-test-report.md) for evidence, rendering limits and capture limitations. Published assets are rebuilt and verified by Windows Release CI from the release commit; the accepted local working-tree ZIP is not distributed as a clean CI build.
