# Compositor native kernels

All upstream kernels and resources are covered by the included MIT license,
[LICENSE-Compositor.txt](LICENSE-Compositor.txt), Wonder Assembly LLC.

- HealPixels.c/.h, PatchPixels.c/.h, DeepPixels.c/.h and CameraRawShadows.bin:
  v1.5.7, commit 9537736da6c324b948cdcba24adf74760498ea14. Shadows SHA256:
  76578539bc45a32817aff669c4e41523d7040f3c691ad35adf0723a70a89a705.
- ContentFill.c/.h: archived v1.4.5 kernel, no longer compiled. PatchPixels is
  the v1.5.7 replacement. The portable scheduler retains the original band
  indices and seeds so scheduling changes do not change PatchMatch output.
- AdjustPixels.c/.h, DitherPixels.c/.h and CameraRawTables.bin: v1.4.9, commit
  0ab3ff58a3dcf3d52a455fe3ab0336ac95923edd, Compositor/Rendering and
  Compositor/Resources. The LUT SHA256 is
  e67ff4dbcce35cb7765752acff4405be5c934d913ef1396b2ca3fc6dc8a85190.

AdjustPixels retains the v1.4.9 runtime adaptations and adds the v1.5.7
region-adaptive Shadows kernel. `scripts/check-mac157-kernels.py` compiles
unmodified upstream C independently and compares the portable output; Rust
integration tests consume the resulting fixed pixel fixtures.

The C arithmetic is retained. Apple dispatch/blocks scheduling is replaced by
serial band loops; runtime includes select bounded Windows/WASM allocation and
math bridges. engine/build.rs compiles these kernels and decompresses the CRT3
resource on the build host; the resulting RGB table is embedded in WASM.

The 16-to-8-bit RAW quantizer in src-tauri/native/RawQuantize.h transcribes
Compositor/Rendering/DitherPixels.c at the same v1.4.9 commit. LibRaw still
develops the actual sensor data; this does not promise Apple CIRAWFilter parity.

`LensToneCurves.bin` is a sampled Core Image tone-curve lookup generated by
`scripts/check-mac157-lens.py` from the fixed v1.5.7 Lens Effects implementation.
It is covered by the same upstream MIT attribution. The probe inputs and hash
are retained with the Mac 1.5.7 comparison receipts; Lens Effects sampling
differences are documented in `docs/superpowers/research/mac-1.5.7-delta.md`.
